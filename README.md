

# Wallpapers

A curated personal archive of high-resolution wallpapers collected from various sources like [Wallhaven](https://wallhaven.cc/), the [Catppuccin](https://github.com/catppuccin/catppuccin) ecosystem, and across the web.

---
## Repository Structure

To keep the collection clean and easy to browse, wallpapers are organized into theme-based directories:

```
Wallpapers/ 
├── aesthetic/
├── cute/ 
├── misc/
├── nature/ 
├── urban/  
└── README.md
```

---

## Contributing & Submitting Wallpapers

Got a wallpaper you'd like to share? Contributions and additions are always welcome! 

1. **Fork** the repository.
2. **Add** your wallpaper image(s) to the appropriate theme folder (`cats/`, `nature/`, `urban/`, or `misc/`). Ensure they are high resolution.
3. **Open a Pull Request (PR)** detailing your additions.
4. Once reviewed, your additions will be merged into the archive!
