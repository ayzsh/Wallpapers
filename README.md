## 🤝 Contributing & Submitting Wallpapers

Contributions are welcome! If you'd like to add a wallpaper to the archive, please follow these steps:

1. **Fork** this repository.
2. **Add** your high-resolution wallpaper(s) to the appropriate folder directory.
3. **Open a Pull Request (PR)** detailing the additions.

Once submitted, I'll review and merge your PR!
